enzo.dev — Portfólio Pessoal

Descrição

Portfólio pessoal desenvolvido para apresentar minha trajetória acadêmica, habilidades e projetos na área de tecnologia. O site também disponibiliza links para contato e um formulário para envio de mensagens.

Tecnologias utilizadas

HTML5: estruturação e organização do conteúdo da página.

CSS3: estilização, layout, responsividade e efeitos visuais.

Git: controle de versão do projeto.

GitHub: hospedagem do repositório e publicação do site com GitHub Pages.

FormSubmit: serviço externo utilizado para receber mensagens do formulário de contato.

Funcionalidades

Apresentação pessoal com foto.

Seção sobre mim e formação acadêmica.

Exibição de habilidades e conhecimentos.

Cards com descrição e links para projetos.

Links para redes sociais e e-mail.

Formulário de contato com validação nativa do HTML.

Layout responsivo para computadores e celulares.
